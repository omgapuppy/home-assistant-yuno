# Security

This integration stores reusable encrypted Yuno login values and session tokens.
Treat them like passwords, whether generated by account setup or supplied manually.

Never commit, upload, or share:

- Raw capture files, HAR files, proxy exports, packet captures, or dumps.
- `.env` files.
- Session tokens.
- `X-Http-sessionToken` values.
- Encrypted Yuno login payload values.
- Generated setup JSON files or helper output.
- Plain account passwords.
- PAN, MPRN, account IDs, names, emails, phone numbers, addresses, or payment details.

The repository `.gitignore` blocks common local secret and capture file patterns. It is still your responsibility to inspect changes before committing.

The integration stores encrypted login values and session tokens in Home Assistant
config entry storage; it does not retain the plain password entered in the account
form. This storage is not a password vault: protect configuration access and
backups. The helper creates owner-only files and does not retry rejected logins.
The integration avoids logging credentials. Debug logs should not include request headers, request bodies, or API responses.

Do not implement or use certificate-pinning bypasses, app attestation bypasses, DRM circumvention, or binary patching for this project.

Report security issues privately to the repository owner. Do not open public issues containing secrets or account data.
